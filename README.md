# Список покупок

Учебное приложение на React и TypeScript: добавление и удаление товаров, подсчёт общей стоимости.

## Запуск

```
npm install
npm run dev
```

Проверка типов и сборка: `npm run build`.

## Как выполнено задание

- `src/App.tsx`: `useState` хранит массив товаров и значения полей формы. `setItems` добавляет и удаляет товары, не изменяя исходный массив.
- `src/ShoppingItem.tsx`: отдельный компонент одного товара. Получает товар (`item`) и функцию удаления (`onRemove`) через props.
- `map` выводит товары, `filter` удаляет товар по идентификатору, `reduce` считает общую стоимость.
- TypeScript в режиме `strict`, типы в `src/types.ts`. Babel не используется: Vite 8 сам компилирует TSX, а `tsc` только проверяет типы.

Список хранится в памяти и сбрасывается после перезагрузки страницы.
